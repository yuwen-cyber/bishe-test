# 噪声视频素材更换说明

## 为什么要换

原来的 1300 条噪声视频复用了 `D:\biyesheji\face_videos` 里同一批人脸素材（实际用到 75 段），
与正式 700 条完全同源，单个源视频最多被复用 **21 次**。带来的问题：

1. 噪声的视觉内容与正式数据无法区分，削弱了"大规模干扰"这一实验设定；
2. 单源复用 21 次，画面重复明显，答辩时容易被质疑数据多样性。

## 新方案

| 项目 | 内容 |
|---|---|
| 素材来源 | Mixkit 免费素材库（Free License，可免费使用），8 个无人物分类 |
| 分类 | nature / city / food / abstract / technology / animals / business / sport |
| 源视频数 | 768 个（清单见 `experiments/noise/source_plan.json`） |
| 素材总量 | 813 MB，总时长 201.7 分钟，平均每段 15.8 秒 |
| 素材文件 | `experiments/noise/sources/{vid}.mp4`（640×360） |

抓取与下载脚本：

- `experiments/fetch_noise_sources.py` —— 每类抓 5 页，提取 360p 直链
- `experiments/download_noise_sources.py` —— 10 并发下载，ffprobe 校验时长 ≥2 秒

## 切片规则

| 项目 | 值 |
|---|---|
| 输出 | `experiments/noise/video/noise_0000.mp4 ~ noise_1299.mp4`（覆盖原文件） |
| 时长 | 保持原 `noise_plan.json` 的 8~12 秒（与 TTS 音频长度对应） |
| 编码 | 640 宽、crf 30、无音轨（与原噪声视频一致） |
| 分配 | 按 noise_id 顺序分配，一源一条为主；用完一轮再进入下一轮，起点错开 |
| 实际重复 | 用到 768 个不同源，**单源最多 2 次，平均 1.69 次**（原为最多 21 次） |
| 映射记录 | `experiments/noise/noise_video_map.json`（每条记录 source / start_sec / duration_sec） |

脚本：`experiments/regenerate_noise_videos.py`

## 入库与向量重建

换视频文件不等于换向量，必须同步更新三处：

1. **MinIO**：用原 `video_object_key` 同 key 覆盖，前端回放立即生效；
2. **image_embedding**：脚本内直接调用 `image_encoder._encode_real()` 走真实 CLIP，
   不受线上 `.env` 中 `USE_REAL_IMAGE=false` 影响；
3. **Milvus**：按 `segment_id` delete 后 insert 同一行，文本/音频/情绪向量沿用原值。

脚本：`experiments/replace_noise_video_and_rebuild.py`
进度：`experiments/output/replace_noise_progress.json`

## 对实验的影响

- 模态消融中的 `image_only` / `text_image` / `text_audio_image` 几组，图像向量现在来自
  **与正式数据完全不同源的场景画面**，图像模态的贡献不再被人脸画面重合干扰；
- 检索鲁棒性（clean vs full）的对比更干净：噪声在视觉上与正式数据无重叠；
- 需要重跑：`eval_offline.py`、`run_ablation.py`、`run_fusion_ablation.py`、
  `run_eval.py`、`run_hybrid_eval.py`、`export_demo_data.py`。

## 需要在论文里写的口径

1. 正式 700 条的**音频**是自己录制的真实语音，**画面**是从公开人脸情绪视频里
   按情绪匹配截取的片段，二者不是同一个人同框录制——这是素材受限下的可复现构造；
2. 噪声 1300 条为 TTS 合成语音 + 网络免费场景素材切片，与正式数据不同源；
3. 噪声情绪为构造标注（与生成意图 100% 一致），正式 700 条为模型预测（一致率 59.1%），
   两者口径不同，需分别说明；
4. 素材许可：Mixkit Free License，论文中注明来源（mixkit.co）与许可类型。

## 追加：影片噪声 227 条（方案 A，2026-11-24 完成）

在上述场景噪声之外，按导师要求引入长视频自动切分的影片片段，作为第二类噪声载体。

| 项目 | 值 |
|---|---|
| 原始片源 | `C:\Users\85764\Downloads\下载的影片`，9 个 mp4，合计 279.4 分钟 / 7.3 GB |
| 去重排除 | 2 号同源节选、1 号与 4 号为同一部片的提亮版 → 实际用 7 个源、232 分钟 |
| 扫描参数 | 人脸检测 1280×720、0.5 帧/秒、pad 2.0 秒（480×270 会漏检 19/20 帧，已弃用） |
| 候选 | 307 条无人脸窗口 |
| 复核剔除 | 逐条抽 6 帧复核，剔除 160 条含人物/近乎全黑片段 |
| 最终入库 | **227 条**，8～10 秒、640 宽、无音轨、crf 30，合计 36.3 MB |
| 编号 | noise_id 1300～1526；db segment_id 2033～2259 |
| 文本 | SUBJ×ACT 词库组合，16～24 字，227 条互不重复（避免与正式数据词汇泄漏） |
| TTS | 五音色轮换；首次 222/227 成功，5 条 NoAudioReceived 补跑后 227/227 |
| 情绪字段 | 构造口径记为中性，归入纯干扰组（与场景噪声的 600 条纯干扰同组） |
| 映射 | `experiments/noise/film_slice_map.json`（含 source_stats、rejected=160、scan 参数） |
| 候选池 | `experiments/noise/film_candidates.json`（307 条） |

各源无人脸片段占比：3 号 77.7%（144 条）、9 号 32.8%（54）、5 号 18.2%（13）、
6 号 18.8%（5）、7 号 18.0%（4）、8 号 9.3%（4）、2 号 35.0%（3）。

**结论**：影片素材能否作"中性噪声"取决于题材而非长度。风光空镜片有效率最高，
叙事纪录片人物密度极高（访谈、面部特写密集），切片产出效率不足 10%。

入库耗时说明：真实情绪模型约 50 秒/条，227 条需 3 小时。影片噪声情绪本就是构造标注，
入库时用 `--skip-emotion` 跳过重复推理，225 条 3.9 分钟完成、失败 0；跳过的只是推理，不是标注。
