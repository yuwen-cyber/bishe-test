# 总体指标口径修正（剔除不可判定查询）

## 为什么改口径

- 原查询集 50 条中有 12 条「结构化精确查询」，形如「找一下 user003 悲伤的对话」。
- 当前数据集为 700 条单片段会话，**没有说话人（user）维度**，这类查询在原理上不可能命中，若计入总体平均会把所有配置的指标系统性拉低（占 12/50 = 24%）。
- 处理方式：不删查询、不改数据，只给出两套口径并明确标注；结构化查询能力另用 20 条「可判定组合条件查询」单独评测（见 `structured_eval.md`）。

## 写论文时的建议说法

- 主表用**有效口径（38 条）**，并在表注写明：剔除了 12 条因缺少说话人维度而不可判定的查询。
- 若需要与历史跑分对齐，附录给出原口径（50 条），并说明其偏低是口径所致、非检索能力下降。
- 结构化精确查询的实测结果单独见 `structured_eval.md`（20 条组合条件查询，精确过滤集合级 P/R/F1 = 1.0）。
