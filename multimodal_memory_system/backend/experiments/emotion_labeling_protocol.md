# 情绪标注协议（实验 1）

> 适用：本课题 700 条单片段会话的情绪人工标注与一致性评估（Cohen's Kappa）。
> 配套脚本：`build_annotation_sample.py`（抽样出题）、`annotate_cli.py`（盲标工具）、`compute_kappa.py`（一致性计算）。

---

## 一、标注目标与标签定义

标注对象是**说话人在该片段中实际表达的主导情绪**，不是文本字面褒贬，也不是对话另一方的情绪。
标签固定 7 类，不允许新增或改写：

| 编号 | 标签 | 判据（怎么判断） | 典型信号 |
|---|---|---|---|
| 1 | 喜悦 | 语气上扬、语速偏快、内容偏正面或满足 | 开心、舒服、松了口气、值得 |
| 2 | 惊讶 | 出乎预期的语气加重、语调突起 | 没想到、居然、突然、怎么会 |
| 3 | 愤怒 | 音量增大、语气强硬、指责或对抗 | 气死、凭什么、太过分、受不了 |
| 4 | 恐惧 | 语气发紧、语速不稳、内容指向威胁 | 害怕、担心、不敢、万一 |
| 5 | 悲伤 | 语速变慢、音量降低、情绪低落 | 难受、失落、没意思、想哭 |
| 6 | 中性 | 平铺直叙，无可见情绪起伏 | 陈述事实、日常叙述、无明显起伏 |
| 7 | 厌恶 | 语气带排斥、嫌弃 | 恶心、烦、受不了这个、嫌弃 |

**边界规则**（必须遵守，否则 Kappa 会被规则分歧污染）：

1. **多情绪并存** → 取语气最强烈的那一种；强度接近时取"说话人更想表达"的那个（通常在句末强调）。
2. **文本与语音冲突** → 以语音韵律（音量、语速、停顿）为主，文本为辅；因为"笑着骂人""平静地说难过"都真实存在。
3. **完全听不出** → 判中性，不要为了"有标签"硬猜。
4. **片段时间太短（<3 秒）或 ASR 明显错乱** → 按 `s` 跳过，不计入有效标注。
5. **同一条不得反复回看超过 3 次**，避免过度斟酌导致个体标准漂移。

## 二、抽样方案（已执行）

- 分层抽样：按库内 7 类情绪比例抽，每类至少 2 条，共 **60 条**（`--size 60`）。
- 固定随机种子 `42`，任何人重跑得到同一批样本（可复现）。
- 实抽结果：喜悦 18、惊讶 14、愤怒 11、恐惧 7、悲伤 4、中性 4、厌恶 2。
- 生成物：
  - `experiments/annotation/tasks.csv` —— 给标注者的清单，**不含原始情绪列**；
  - `experiments/annotation/answer_key.csv` —— 原始标签，**标注过程中不得打开**。

> 导师文档要求 80~120 片段、2~3 人对同一批标注。当前 60 条是**流程验证 + 小样本试点**规模；
> 正式实验时用 `--size 100` 重跑即可扩样，脚本支持。

## 四、Kappa 判读标准（论文直接引用）

Cohen's Kappa 扣除随机一致后衡量真实一致性：`κ = (Po − Pe) / (1 − Pe)`。
判读采用 Landis & Koch (1977) 常用分档：

| Kappa | 判读 |
|---|---|
| < 0 | 差于随机 |
| 0.00 ~ 0.20 | 轻微一致 |
| 0.21 ~ 0.40 | 一般一致 |
| 0.41 ~ 0.60 | 中等一致 |
| 0.61 ~ 0.80 | 较强一致 |
| 0.81 ~ 1.00 | 几乎完全一致 |

**合格线建议**：情绪这类主观任务，κ ≥ 0.60（较强一致）即可接受；κ < 0.40 需回到协议、重新对齐判据后补标。

## 五、论文/答辩必须写清的三件事

1. **Kappa 是标注者之间的一致性，不是标注者与模型的差距。**
   `compute_kappa.py` 里另有一项「与原始标签的一致率」——它衡量"人工 vs 库里原始标签"，
   属**参考指标**，不能冒充 Kappa，两者必须分开表述。
2. **本数据的"盲"是有限盲标。**
   任务清单已屏蔽原始情绪列，标注者看不到模型结果，但 **ASR 文本本身含情绪词**（如"特别开心"），
   语义线索无法屏蔽。因此本实验的盲标只能防止"被原标签锚定"，不能当作严格的内容盲评。
3. **单人数据不能出 Kappa。**
   只有一名标注者时，脚本会输出"Kappa 无法计算（待第二标注者）"，这是正确状态，不要改数或估算。
